# Y.U.R.I.-
Your Universe Rendered Interactively (Y.U.R.I.) is a collaboration between 5 Texas A&amp;M Freshman Engineering Students created for the Lunar Site Navigation Challenge in the 2026 NASA Space Apps Hackathon. Joanne Sawahri (Team Lead), Mathew Nugara, Rachel Yi, Dan Nguyen
